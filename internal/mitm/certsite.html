iPhone / iPad{{if eq .Platform "ios"}}this device{{end}}
  1. Open this page in Safari and tap Download certificate, then Allow.
  2. Open Settings › General › VPN & Device Management, tap the Chapar profile and Install.
  3. Open Settings › General › About › Certificate Trust Settings and turn on full trust for {{.Name}}.
Android{{if eq .Platform "android"}}this device{{end}}
  1. Tap Download certificate.
  2. Open Settings › Security › More security settings › Encryption & credentials › Install a certificate › CA certificate and pick the file.

Apps targeting Android 7+ ignore user certificates unless they opt in, so most app traffic stays hidden. Browsers like Chrome do accept them.

macOS{{if eq .Platform "macos"}}this device{{end}}
  1. On the Mac running Chapar, use Trust in Chapar’s proxy setup instead: it does all of this for you.
  2. On another Mac: download the certificate, open it in Keychain Access, double-click {{.Name}} and set When using this certificate to Always Trust.

Or in Terminal: security add-trusted-cert -r trustRoot -k ~/Library/Keychains/login.keychain-db chapar-ca.pem

Windows{{if eq .Platform "windows"}}this device{{end}}
  1. Download the certificate and open it.
  2. Choose Install Certificate › Current User › Place all certificates in the following store › Trusted Root Certification Authorities.

Or in a terminal: certutil -user -addstore Root chapar-ca.cer

Linux{{if eq .Platform "linux"}}this device{{end}}

Debian / Ubuntu:

sudo cp chapar-ca.pem /usr/local/share/ca-certificates/chapar-ca.crt && sudo update-ca-certificates

Fedora / RHEL / Arch:

sudo trust anchor --store chapar-ca.pem

Firefox

Firefox keeps its own trust store. Open Settings › Privacy & Security › Certificates › View Certificates › Authorities › Import, pick the file and tick Trust this CA to identify websites.
